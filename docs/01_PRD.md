# 01 · 产品需求文档（PRD）

## 1. 问题

入职有两半：**学材料**和**学人**。公司通常把前一半做得很完整（手册、流程、培训课程），后一半却几乎没人设计，全靠新人自己的性格和运气。

- 社恐的新人、实习生和国际员工缺的不是信息，而是**一个去找人的正当理由**。没有契机，coffee chat 一拖再拖，入职进度也被拖慢。
- 在职同事往往**不知道有新人来了**，也不知道自己该做什么。
- HR 能追踪培训完成率，却**看不到新人是否真的融入了团队**。

不解决的代价：新人要花更长时间才知道"遇到问题该找谁"，孤立感更强，早期流失风险更高。

## 2. 核心洞察

> 游戏给了新人一个开口的借口，也让"和新人聊天"成为同事被认可的工作内容，而不是私人打扰。

## 3. 目标

| # | 目标 | 衡量方式 |
|---|---|---|
| G1 | 新人在入职第一周认识所有关键同事 | 第 5 天前收集完全部关键同事卡片的新人比例 |
| G2 | 新人知道"遇到问题该找谁" | "Who do I ask?" 小测验正确率；第 1 天与第 5 天的自评变化 |
| G3 | 新人和同事之间发生真实对话，而不只是扫码 | fun fact 解锁率（只能当面问到答案） |
| G4 | 同事参与成本极低 | 同事完成卡片设置的中位时长 < 2 分钟 |
| G5 | HR 能看到融入进展 | HR 控制台实时显示每位新人的进度，无需手动统计 |

## 4. 非目标（这一版不做）

| 不做 | 原因 |
|---|---|
| 真实的账号系统与企业 SSO | 黑客松演示用"加入码 + 选择身份"即可；架构上预留 |
| 手机对手机 NFC 碰一碰 | iPhone 网页无法实现；用二维码，产品愿景里讲 NFC 工牌 |
| 新人之间或同事之间的排行榜 | 会制造社交压力，违背"降低社恐"的初衷 |
| 聊天 / 私信功能 | 目的是促成线下见面，不是把对话搬进 App |
| 原生 iOS / Android App | 网页即可满足"能在手机上运行"，开发快一个数量级 |
| AI 自动生成内容 | 不是这版的核心价值，时间留给体验打磨 |

## 5. 用户与人物画像

| 角色 | 画像 | 核心需求 | 最大顾虑 |
|---|---|---|---|
| 新人 | Yunfei，国际设计实习生，有点社恐，第一次在瑞典公司工作 | 认识人、知道找谁、不尴尬地开口 | 打扰别人、被拒绝、记不住名字 |
| 同事 | Oskar，忙碌的后端工程师，愿意帮忙但不会主动注意到新人 | 少花时间、知道谁是新人 | 又多一个要填的系统 |

## 6. 用户故事

### 新人

- **N1** 作为新人，我想在入职前就看到 5 位关键同事的卡片（脸、名字、职位、可以找他们聊什么），这样第一天见面时不会完全陌生。
- **N2** 作为新人，我想扫描同事的员工卡二维码来收集他们的卡片，并看到一个令人开心的揭晓动画，这样认识一个人就像获得一张稀有卡。
- **N3** 作为新人，我想在每张同事卡上看到一两句开场白建议，这样我走过去时知道第一句说什么。
- **N4** 作为新人，我想通过当面问出答案来解锁同事的 fun fact，这样我有理由多聊几句。
- **N5** 作为新人，我想在卡片背面写下对这个人的第一印象和他说过的一句话（只有我能看到），这样我能记住他。
- **N6** 作为新人，我想做一个"遇到问题该找谁"的小测验，这样我确认自己真的记住了谁负责什么。
- **N7** 作为新人，我想在集齐关键同事后解锁 onboarding party，并自动邀请这些同事一起 fika，这样第一周有一个温暖的结尾。
- **N8** 作为新人，当同事不在或没设置卡片时，我想看到清楚的提示和替代选项，而不是一个错误页面。

### 同事

- **C1** 作为同事，我想在两分钟内设置好自己的卡片（像素头像、职位、找我聊什么、fun fact 问题与答案），这样不会占用我的工作时间。
- **C2** 作为同事，我想知道本周有哪些新人入职、我是不是他们的关键同事，这样我能有所准备。
- **C3** 作为同事，当新人收集我的卡片时，我想收到通知并获得他们的新人卡，这样我也知道他是谁。
- **C4** 作为同事，我想设置"现在欢迎来聊"的状态，这样新人知道什么时候来找我不算打扰。
- **C5** 作为同事，我想随时隐藏或修改我的卡片，这样我对自己的信息有控制权。

### HR

- **H1** 作为 HR，我想录入团队成员（或使用演示数据），并给每人发出"领取你的卡片"链接。
- **H2** 作为 HR，我想为新人创建入职任务：选择 5 位关键同事并写明原因（如"你的导师"、"IT 问题找他"），然后发出邀请链接。
- **H3** 作为 HR，我想实时看到每位新人的进展（已收集几张、解锁几个 fun fact、测验得分），这样能及时介入。
- **H4** 作为 HR，我想看到团队层面的成效指标（同事卡片完成率、新人平均首次对话时间、第 5 天自评），这样能向管理层证明价值。
- **H5** 作为 HR，我想一键重置演示数据，这样可以反复演示。

## 7. 需求

### P0 必须完成（没有它们就讲不通故事）

| ID | 需求 | 验收标准 |
|---|---|---|
| P0-1 | 身份进入 | 首页输入加入码 `FIKA24` → 选择"我是谁"（列表显示头像与职位）→ 进入对应角色首页。身份保存在本机，刷新不丢失。有"切换身份"入口。 |
| P0-2 | 员工卡组件 | 卡片包含：部门色全息边框、编号、像素头像、名字、职位、"Ask me about" 话题、fun fact 区（锁定时显示 `???` 与锁图标）。尺寸可缩放，在 390px 宽屏幕上清晰可读。 |
| P0-3 | 同事"我的卡片"页 | 显示自己的卡片与大尺寸二维码（指向 `/c/:qrToken`）、"Open to chat" 开关、"Edit my card" 入口。 |
| P0-4 | 同事编辑卡片 | 可修改：头像（发色、肤色、衣服色）、职位、部门、Ask me about（最多 3 个话题）、fun fact 提示问题、fun fact 全文、答案关键词。保存后卡片立即更新，`card_claimed = true`。 |
| P0-5 | 扫码收集 | 新人用手机原生相机扫同事二维码 → 打开 `/c/:token` → 自动收集 → 播放翻卡揭晓动画 → 显示"New card!"与这张卡。重复扫描显示"Already in your Teamdex"，不重复计数。扫自己的码显示自己的卡片。未登录时先引导进入，再自动完成收集。 |
| P0-6 | 双向交换 | 收集时同时为同事创建一条"收到新人卡"的记录。同事在 5 秒内（Supabase 模式下实时）看到通知 "Yunfei collected your card"，并能在自己的收藏里看到新人卡。 |
| P0-7 | 新人收藏页（Teamdex） | 网格显示：关键同事（未收集时为灰色剪影 + 名字 + 原因）在前，其他同事在后。顶部进度 `3 of 5 key colleagues`。点击已收集卡片进入详情。 |
| P0-8 | fun fact 当面解锁 | 卡片详情显示提示问题（如 "Ask Oskar how he gets to work in winter"），输入框输入答案 → 匹配关键词则解锁，播放解锁动画并显示全文；不匹配显示 "Not quite. Ask them again!"。答案在前端不可见（Supabase 模式由数据库函数校验）。 |
| P0-9 | "Who do I ask?" 小测验 | 至少收集 3 张卡后解锁。5 道题，每题一个工作场景（来自同事的 help topics），从已收集的同事中选择 4 个选项，选对得分。结束显示得分与每题正确答案。 |
| P0-10 | Onboarding party | 集齐关键同事后自动解锁：像素小人跳舞的庆祝页（新人 + 所有关键同事的头像），显示 "Fika invite sent to …"，并向这些同事发出 party 通知。 |
| P0-11 | HR 控制台：新人进度 | 列出所有新人，每人显示进度条（x/5）、已解锁 fun fact 数、测验得分、最近动态。实时刷新。 |
| P0-12 | HR 控制台：创建入职任务 | 选择一位新人（或新建）、勾选 5 位关键同事、为每位填写原因、生成邀请链接与二维码。 |
| P0-13 | 实时动态流 | HR 与同事首页能看到事件流（收集、解锁、party），新事件出现时有轻提示。 |
| P0-14 | 演示数据与重置 | 演示公司 Fika Labs（加入码 `FIKA24`）预置 8 位同事（其中 Viktor 尚未领卡）、2 位新人：Yunfei（任务刚创建，0/5，用于现场演示）与 Noor（已集齐并解锁 party，用于备份和展示 HR 数据）。HR 控制台有 "Reset demo" 按钮，一键恢复。 |

### P1 有时间就做（显著提升体验）

### P2 未来考虑（本次不做，但架构要能支持）

- 真实账号：Supabase Auth 魔法链接或企业 SSO，按 `auth.uid()` 做行级权限
- NFC 工牌：同一个 `/c/:token` 网址写进 NFC 贴纸或工牌即可，无需改动逻辑
- 与 Uniplay 平台集成：团队名单作为"内容"导入，新人进度回传到学习路径
- 多语言界面（瑞典语、中文）
- Slack / Teams 通知

## 8. 成效指标

| 类型 | 指标 | 目标（试点假设） |
|---|---|---|
| 先行 | 同事卡片设置完成率（邀请后 48 小时内） | ≥ 80% |
| 先行 | 新人首次收集卡片的时间（入职后） | ≤ 4 小时 |
| 先行 | fun fact 解锁率（已收集卡片中） | ≥ 60% |
| 学习 | 测验正确率 | ≥ 80% |
| 学习 | "I know who to ask for help" 自评，第 5 天 vs 第 1 天 | 平均提升 ≥ 1.5 分 |
| 滞后 | 新人 90 天留存、30 天融入感调查 | 相比无 Teamdex 的入职批次提升 |
